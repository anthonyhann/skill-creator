## 异常处理

| 场景 | 处理 |
|------|------|
| 状态转换条件不明确 | 展示当前状态和可选转换，等用户选择 |
| 回退超过最大次数 | 中止，展示已完成的步骤和部分结果 |
| 依赖缺失 | 前置检查，缺失则不进入状态机 |

## 诚实边界

- 不对未定义状态进行推断式跳转。
- 状态机规则冲突时必须停机并请求用户确认。
